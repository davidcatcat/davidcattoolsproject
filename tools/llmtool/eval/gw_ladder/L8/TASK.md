Implement `select_rule(record, rules, mode="first")` in `target.py`. `record` is a dictionary. A rule has a string `name`, a dictionary `conditions`, and, for priority mode, an integer `priority`. A rule matches when every condition field has the same value in `record`; an empty conditions dictionary matches every record. Return the selected rule's name, or `None` if no rule matches. Mode `first` selects the first matching rule in input order. New mode `priority` selects the matching rule with the greatest priority; ties select the first matching rule in input order. Empty rules return `None` in either mode. Raise `ValueError("mode must be 'first' or 'priority'")` for any other mode, `ValueError("rules must be a list")` unless rules is a list, `ValueError("each rule needs name and conditions")` for a rule whose name is not a string, which lacks either field, or which has a non-dictionary conditions value, and `ValueError("priority must be an integer")` when priority mode has a missing, boolean, or non-integer priority. Use the existing `prepare_rules` and `matches` functions; read their implementations to determine their input and output behavior.
