## Workflow 摘要

- **觸發：** `pull_request`、推到 `main`／`feat/**` 的 `push`（兩者都限定路徑 `tools/nlf/**` 與 workflow 本身），以及 `workflow_dispatch`。不使用 `pull_request_target`。
- **權限：** `permissions: contents: read`；checkout `persist-credentials: false`；沒有 secrets、沒有 publish、沒有 artifact upload、沒有 cache；`run:` 內沒有任何 `${{ }}` 展開。
- **Matrix：** `ubuntu-latest`、`macos-latest`，`fail-fast: false`，`timeout-minutes: 15`。
- **Go：** `actions/setup-go` 搭配 `go-version-file: tools/nlf/go.mod`（刻意測試 go.mod 宣告的最低版本 1.23），`GOTOOLCHAIN=local`、`GOPROXY=off`。
- **Pinned actions**（以 `git ls-remote` 驗證；兩者都是 lightweight tag，SHA 即 commit）：
  - `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1` (v7.0.1)
  - `actions/setup-go@b7ad1dad31e06c5925ef5d2fc7ad053ef454303e` (v7.0.0)
- **Steps：**
  1. 顯示 toolchain
  2. `make fmt-check`
  3. `make vet`
  4. `go test -count=1 -v ./...` + skip guard（Linux 不允許 skip；macOS 只允許 `TestGNUSortPipeline`）
  5. `go test -race ./...`
  6. `go test -count=10 -shuffle=on ./...`
  7. `make build`
  8. `make dist`
  9. `SHA256SUMS` 必須正好列出 4 個預期檔名，並通過 `sha256sum -c`／`shasum -a 256 -c`
  10. Linux binary `file` 顯示 statically linked（Linux runner 上缺少 `file` 視為失敗）；4 個 dist binary 都是 `CGO_ENABLED=0`
  11. `scripts/ci-smoke.sh` 實際執行 `bin/nlf` 與本機平台的 dist binary（`uname` 與 `go env GOHOSTOS GOHOSTARCH` 交叉比對）
  12. `git status --porcelain` 必須為空

## Smoke script

fixture 建在新的 `mktemp -d`（以 `pwd -P` 取得真實路徑），不使用 `rm`。檢查 `--version`／`--help`、6 個有結果的查詢（精確比對排序後的路徑，含 CJK 路徑）、exit 1（沒找到）、4 個 exit 2（錯誤輸入）、`--explain` 顯示平台、`--confirm` 的 n／y／EOF、以及 read-only（cksum snapshot 與 `-newer` marker）。相容 bash 3.2。

## 已知取捨與後續

- `feat/**` 分支若同時開了 PR，每個 commit 會跑兩次（push 與 pull_request 的 concurrency group 不同）。private repo 的 macOS 分鐘數較貴；之後可考慮把 `push` 限縮到 `main`。
- 只測 go.mod 的最低版本；之後可在 matrix 加 `stable`。
- 路徑過濾代表沒改到 nlf 的 PR 不會產生這個 check；若日後設為 required status check 需要另外處理。
- `TZ=Pacific/Auckland` 下 `TestExplainDoesNotSearch` 與 `TestLongOutput` 會失敗（`testNow` 落在 DST 開始日）；CI 使用 UTC 不受影響，後續另外修，不放寬 assertion。
- README 中「Linux 尚未實際執行測試」的描述已依 run `36365761225` 的結果更新。
