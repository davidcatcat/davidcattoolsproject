# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub private vulnerability reporting. Open the repository Security tab and choose "Report a vulnerability". You can also use this link:

https://github.com/davidcatcat/davidcattoolsproject/security/advisories/new

Do not open a public Issue, pull request, discussion or comment for a suspected vulnerability.

## What to include

Please include:

- The affected file or component.
- The revision or commit.
- Steps to reproduce the problem.
- The expected impact.

Use made-up example values. Never include real credentials, personal data or private logs.

## Supported versions

Only the latest commit on the main branch is supported. There are no released versions.

## What happens next

Reports are handled on a best-effort basis by a single maintainer with AI assistance. There is no bug bounty. After a fix is reviewed, it is published in the normal way.

## Scope

This policy covers the code and workflows in this repository. Problems in third-party services or tools belong with their own maintainers.
