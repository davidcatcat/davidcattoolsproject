# llmtool TUI Owner 重測清單（繁體中文）

- 用途：Issue #683 交付物 4，供 Owner 依序手動重測 TUI。
- 依據：[2026-10-22 UI/UX 設計決策文件](../meetings/2026-10-22-llmtool-tui-ui-ux-decision.md)。以下期望結果均取自該文件；本文件不記錄任何測試結果，亦不含測試計畫。
- 狀態基準：狀態指該文件所述的實作狀態；文件未明載者一律標記 UNKNOWN。該文件開頭即聲明「僅規劃文件，尚非實作／驗收結果」。
- 資料安全：測試內容一律使用一般文字，不得輸入密碼、金鑰、token 等憑證樣式字串；涉及授權拒止的行為應以 mock 或注入方式驗證，不用真實憑證輸入。

## 1. 滑鼠輪與觸控板捲動

- 步驟：
  1. 開啟 `llmtool chat --tui`，等待對話出現。
  2. 分別以滑鼠輪上、下捲動；以觸控板雙指捲動。
- 期望結果：中央對話區可捲動，使用者／AI 訊息區分清楚（決策文件 §2）；捲動後保留捲動位置（§3 對話區）。
- 狀態：UNKNOWN（文件僅述「捲動」已有 source（§4），未述滑鼠輪／觸控板輸入方式，未述驗收結果）。

## 2. 長 CJK 輸出

- 步驟：
  1. 在 TUI 中要求一段長中文回覆（含 Markdown 與程式碼區塊）。
  2. 觀察長輸出的顯示，並嘗試詳細事件展開／收合。
- 期望結果：長輸出有截斷提示，詳細事件可展開／收合（§3 對話區）；證據原樣保留、輸出需 escape 終端控制序列；中文與 Unicode 渲染為可重現測試項目（§5）。
- 狀態：UNKNOWN（文件未述本場景實作狀態或驗收結果）。

## 3. 拖曳選取複製

- 步驟：
  1. 在對話區以滑鼠拖曳選取一段文字或程式碼區塊。
  2. 以終端機複製後貼到另一個純文字位置，核對內容。
- 期望結果：文件將「複製與易讀性調整」列為 P2 項目，並依 P2 回歸方向（終端機寬度、Unicode、降級與操作穩定性）驗證（§4）。
- 狀態：UNKNOWN（文件未述選取複製已實作，僅列於 P2 項目）。

## 4. Ctrl-R

- 步驟：
  1. 在輸入框輸入並傳送幾筆不同的內容。
  2. 按 `Ctrl+R`，輸入關鍵字搜尋歷史。
- 期望結果：`Ctrl+R` 搜尋輸入歷史；終端機無法辨識的組合應可退回替代鍵位，不破壞現有退出、貼上與非 TTY 降級（§3 快捷鍵提案）。
- 狀態：UNKNOWN（文件列為提案且「實作前檢查相容性及衝突」；歷史搜尋為 P0 項目，未述實作狀態）。

## 5. 斜線選單（Slash menu）

- 步驟：
  1. 在輸入框輸入 `/`。
  2. 續輸入關鍵字搜尋，以方向鍵移動並確認選項。
- 期望結果：輸入 `/` 可打開指令選擇器（§2）；可搜尋、方向鍵移動與確認，並顯示命令說明與可用性提示；僅展示現有 Core 支援的操作，不可用指令不得冒稱已實作（§3 指令選單）。
- 狀態：UNKNOWN（Slash 命令搜尋為 P0 項目，未列入文件所述既有實作清單，未述實作狀態）。

## 6. 多行貼上

- 步驟：
  1. 準備一般文字組成的多行內容（不含憑證樣式字串）。
  2. 以終端機複製貼上到輸入框；再切換焦點、退出後重新進入，觀察輸入框。
- 期望結果：多行輸入、穩定貼上、草稿保留；不因切換焦點／退出而重送（§3 編輯區）。
- 狀態：UNKNOWN（文件述「多行輸入」已有 source；「穩定貼上」屬 P0 項目，未述實作／驗收結果）。

## 7. 視窗縮放（resize）

- 步驟：
  1. 對話中把終端機窗口拖至窄寬度，觀察版面與狀態列。
  2. 再拉回寬寬度，並捲動對話區。
- 期望結果：窄終端依優先度隱藏狀態列欄位（§2、§3 狀態列）；捲動／縮放為可重現測試項目（§5）；P2 回歸涵蓋終端機寬度與操作穩定性（§4）。
- 狀態：UNKNOWN（窄視窗為 P0 項目，文件未述實作狀態或驗收結果）。

## 8. PM 佇列與 Esc

- 步驟：
  1. 於 Core 能提供資料時，由選單進入 Task／Approvals 子畫面（佇列列表）。
  2. 在佇列畫面按 `Esc`。
- 期望結果：Task／Agent／Approvals 採需要時開啟的子畫面／選單，只在 Core 真能供資料時可用（§2、§3 頁面切換）；確認畫面僅顯示 Core 傳來的操作對象、範圍及結果，UI 不自行判斷權限或自動核准（§3 操作確認）；`Esc` 為返回（§3 快捷鍵提案）。
- 狀態：UNKNOWN（文件未述該入口與 `Esc` 鍵的實作狀態；PM／Integrator 語意判斷與派工策略被明確排除於 TUI 之外（§1））。

## 9. 無訊息遺失

- 步驟：
  1. 連續傳送數筆訊息，再切換至子畫面後返回。
  2. 核對對話區訊息的順序與內容，確認沒有重複傳送。
- 期望結果：使用者／AI 訊息於中央區區分清楚並完整顯示（§2）；未重送 prompt（§5 DoD）、草稿保留（§3 編輯區）。注意：文件述目前對話歷史僅在記憶體、Session 持久化不屬 TUI 範圍（§1、§4），不應對跨重啟留存寄予期望。
- 狀態：UNKNOWN（文件未述訊息遺失防護的實作狀態或驗收結果）。
